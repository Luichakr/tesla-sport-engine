# Credits — звуковые материалы

## Моторы реальных машин (`sounds/cars/*`, кроме `sim_*`)
Студийные записи из бесплатных **Sonniss GDC Game Audio Bundles**
(https://sonniss.com/gameaudiogdc). Лицензия royalty‑free: можно использовать
в своих проектах без указания авторства; не распространять как отдельную
библиотеку звуков и не использовать для обучения ИИ.

- **Pole Position Production** — BMW M4 2014, Ferrari 488 2016, Mercedes‑AMG C63 2009,
  Nissan 370Z 2012, Honda S2000 2002, а также запуски Ferrari 812 Superfast,
  McLaren 570S, Corvette C6 Z06.
- **Soundholder** — Lexus LFA 4.8 V10, Porsche Cayenne 4.8 V8, Subaru Impreza GD WRX.

Изменения: вырезаны участки на постоянных оборотах, на стыке луп сведён
кросс‑фейдом 60 мс, выровнена громкость (только усиление), 48 кГц / 16 бит FLAC.

## Моторы «Симулятор» (`sounds/cars/sim_*`)
Наборы лупов через каждые 1000 об/мин из **Stunt Rally 3**
(https://github.com/stuntrally/stuntrally3), автор **CryHam**, лицензия **CC‑BY 4.0**.
Записаны в физическом симуляторе двигателя engine‑sim.

## Хлопки в выхлоп (`sounds/pops/*`)
- Audi R8 Idling Reving Backfire — **Jonas_Jocys**, Freesound #457733, CC‑BY 4.0
- car pass by afterfire crackle tune — **klankbeeld**, Freesound #873008, CC‑BY 4.0
- Car Antilag No cleanup — **modusmogulus**, Freesound #797835, CC0
- S012 Engine Backfire — Freesound #385935, CC0
- backfire.wav — TORCS / Speed Dreams, GPL‑2.0

Изменения: нарезка на отдельные хлопки, нормализация пика, FLAC.
Синтезированные хлопки (режим «синтез») генерируются в браузере.
